# VESPER changelog

## 1.1.0 (2026-10-29)
- Smoother screen. VESPER now draws the next 16-row strip while the previous one is being sent to the display, so HOME, the mixer and page changes feel quicker.
- About 8 KB more free memory. The unused DX7 factory table keeps a single voice.
- SEQ now has 5 pages. The per-track MIDI pages are gone; GLO keeps the global MIDI settings.
- VESPER's own identity, `FM-1_8837001`, replaces M-VAVE's open V14 default.

## 1.0.0 (2026-10-29)
First release.
- **Effects:**
  - Global chain DIRT → TONE → TEXTURE → VERB + DELAY, with tall faders and smooth knob glides.
  - Readable values: %, bits, kHz and dB.
  - TEXTURE has a tempo-synced granular cloud and a band-limited octave shimmer.
- **HOME:**
  - Crystal orbit home screen with the key in the centre.
  - SPACE macro on K2.
  - Mixer with live meters and SEL-hold pan.
- **Controls and screens:**
  - SEL as a hold key for fine steps.
  - Per-voice EDIT pages, including MIX: level, pan and sends.
  - GLO colour themes.
  - The preset name is shown large, with an edited marker.
